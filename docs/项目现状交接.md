## 1. 项目是什么

**取件助手（Express Pick）**：聚合淘宝/菜鸟身份码与取件码的 Android App。
核心路线：**WebView 加载平台官方 H5 页面**（阶段0已验证可行），不做平台逆向。

**必读文档**（按顺序）：
1. `README.md` — 项目概览与进度清单
2. `AGENTS.md` — 开发约定（代码规范/目录结构/提交规范/完成标准）
3. `取件助手需求文档.md` — 需求与验收表
4. `取件助手设计文档.md` — 架构与接口设计
5. `阶段0技术验证报告.md` — 技术可行性结论（真实URL/登录机制/快递100否决）

**技术栈**：Flutter 3.47.5 + Dart 3.13 ｜ Riverpod（AsyncNotifier）｜ GoRouter ｜ sqflite ｜ webview_flutter 4.14
**目标平台**：Android 为主（用户真机为安卓，minSdk 26）；iOS 暂缓

## 4. 架构速览

```
lib/
├── main.dart                       # 开DB→构建仓库→ProviderScope overrides 注入
├── app/                            # app.dart / routes.dart（buildAppRouter工厂）/ theme.dart
├── core/
│   ├── config/platform_config.dart # 读 assets/platform_config.json（URL与选择器唯一来源）
│   └── webview/login_state_detector.dart  # 登录态检测（DOM文本判断，含归一化）
└── features/
    ├── pickup/
    │   ├── domain/    # PickupCode模型、PickupPlatform枚举、PickupCodeRepository抽象接口
    │   ├── data/      # SqflitePickupCodeRepository、PickupCodeSyncService+Extractor
    │   └── presentation/  # 列表/详情/录入页 + pickup_providers.dart（AsyncNotifier）
    ├── auth/          # PlatformAuthRepository抽象 + WebviewAuthRepository(清Cookie)
    │                  #   + IdentityCodePage（WebView身份码页，三态登录横幅）
    └── settings/      # 设置页（平台配置展示/退出登录/清空已取件）
```

**数据流**：UI → `pickupListProvider`(AsyncNotifier) → `repositoryProvider`(`PickupCodeRepository` 抽象) → SQLite / 测试内存实现。
**同步链路**：列表页 initState/下拉刷新 → `syncAndRefresh()` → `syncServiceProvider` → 逐平台读配置 `pickupUrl`（未配置则跳过）→ 离屏 WebView 注入提取脚本 → `PickupCodeExtractor.parse` → 按去重键（platform+code+pickupPoint）upsert。

**约定红线**：
- 平台枚举用 `PickupPlatform`（勿与 dart:io Platform 撞名）
- 公开注释用中文；每任务过 `flutter analyze` + `flutter test`
- 提交格式 `<type>(<scope>): <subject>`（type：feat/fix/docs/refactor/test/chore）

## 5. 踩坑记录（务必先读）

1. **sqflite 在 widget 测试中挂起**：sqlite_ffi 结果走原生事件端口，FakeAsync 环境永远等不到 → widget 测试必须注入内存仓库（`test/helpers/memory_pickup_code_repository.dart`），仓库抽象接口不可删。
2. **路由状态泄漏**：全局单例 GoRouter 会在测试间保留导航状态 → 用 `buildAppRouter()` 工厂，每个 ExpressPickApp 实例独立持有。
3. **webview_flutter 4.14 的 Cookie API** 是 `WebViewCookieManager().clearCookies()`（不是 WebViewCookieHandler）。
4. **dart format 会改动文件**：格式化后再用 Edit 工具改文件会报"modified since read"，需重新 Read。
5. **Android SDK 手动安装布局**：`build-tools_r36_windows.zip` 解压出的目录叫 `android-16`，已改名 `36.0.0`；license 文件已写入 `C:\Android\Sdk\licenses\`（标准哈希）。**不要用 sdkmanager 联网安装**（Google 被墙），缺组件去腾讯镜像下 zip 手动解压。
6. **`flutter build` 需显式 `export ANDROID_HOME="C:\Android\Sdk"`**（local.properties 不够）。
7. 首次 Gradle 构建会从阿里云/腾讯镜像拉依赖，需等待；`services.gradle.org`、`dl.google.com` 直连必失败，别浪费时间重试。
