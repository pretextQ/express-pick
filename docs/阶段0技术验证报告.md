## 2. 详细发现

### 2.1 身份码 H5 页面（✅ 已确认）

- **入口 URL**（来源：公开教程，实测有效）：
  `https://market.m.taobao.com/app/cn-yz/multi-activity/authCode.html`
- **实际落地页**（入口自动重定向，页面标题「身份码」）：
  `https://page.cainiao.com/cn-app-web/identity-code/index.html#/?source=&bizEntry=TAOBAO_GUOGUO`
- **未登录行为**：页面正常加载，弹出「您需要登录才能继续访问」提示层，内嵌登录 iframe。
- **登录 iframe 指向**：
  `https://login.m.taobao.com/login.htm?ttid=h5@iframe&redirectURL=//h5.m.taobao.com/other/loginend.html?origin=https%3A%2F%2Fpage.cainiao.com`

### 2.2 淘宝 H5 登录页（✅ 基本可行，滑块待真机复验）

- 直接访问 `https://login.m.taobao.com/login.htm` 会重定向至
  `https://login.m.taobao.com/havanaone/login/login.htm?bizEntrance=taobao_h5&bizName=taobao`
- **页面功能完整**：手机号输入（+86 及国际区号）、获取验证码、协议勾选、账号密码登录切换。
- **无 UA 拦截**：普通 Chromium UA（非淘宝/菜鸟容器）正常加载渲染。
- **风控组件已加载**：页面引入 `baxia`（阿里无痕风控）与 `AWSC` 组件，滑块/无痕验证在触发时动态出现（点击「获取验证码」或提交时）。本次未实际提交手机号，**滑块能否在第三方 WebView 中通过需真机人工复验**。
- **登录态载体确认**：登录过程中 `.taobao.com` 域写入 `t`、`_tb_token_`、`cna`、`isg`、`tfstk` 等会话 Cookie。

### 2.3 菜鸟与淘宝登录态打通（✅ 机制确认）

身份码落地页在 `page.cainiao.com`，登录通过 iframe 加载 `login.m.taobao.com`（淘宝 H5 登录），登录成功后回跳 `h5.m.taobao.com/other/loginend.html` 再回到菜鸟页面。**即：菜鸟身份码页面的登录态就是 `.taobao.com` 域 Cookie**。App 内只需保证 WebView CookieManager 持久化 `.taobao.com`（及 `.cainiao.com`）Cookie，即实现「共用淘宝登录态」。

### 2.4 H5 取件码数据 JS 提取（⚠️ 未验证）

需要登录态才能看到取件码列表的真实 DOM/接口。**遗留项**：用户用本人手机号登录后，确认页面结构并回填选择器（或改走接口抓包方案）。

### 2.5 快递100「驿站取件码API」（❌ 对个人不可用）

- 该 API 为 2026 年 1 月上线的**企业级订阅推送产品**：下单后、包裹入站前，提交单号+回调地址，入站后由系统推送取件码/驿站名/地址；覆盖 140+ 驿站品牌。
- **需要企业账号、API Key 与商务报价**，且是「提前订阅」模式，不支持「事后按单号查询取件码」。
- 竞品快递鸟（kdniao.com）取件码 API 同样面向 B 端。
- **决策**：P2「快递100 按单号查取件码」路线移除；取件码补充来源改为 Android 短信/通知识别 + iOS 手动录入（短信原文本身包含取件码）。

## 5. 风险提示

- **平台政策风险**：2024 年 5 月支付宝「菜鸟」小程序曾下架身份码入口（"变相强制下载 App"舆论事件），说明阿里对该入口的第三方可达性持收紧态度；本方案依赖的公开 H5 链接随时可能收紧或失效，**必须配置文件化以便随时切换**。
- **服务条款风险**：页面为官方 H5，但"聚合展示"行为本身未获平台授权，存在被风控/封禁的可能，不应做高频自动轮询。
- 登录页风控对异常环境（模拟器、频繁登录、非常用 IP）可能加验滑块甚至拒绝，需控制登录频率并保留手动登录兜底。
