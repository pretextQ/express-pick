# 取件助手 (Express Pick)

聚合多个购物平台和快递服务的取件码，用户无需打开多个App即可快速查看和使用取件码。

## 功能特性

- 取件码聚合：聚合淘宝、拼多多、菜鸟等平台取件码
- 身份码展示：支持各平台身份码直接展示
- 取件提醒：新取件码自动通知
- 历史记录：查看历史取件记录

## 技术方案

- 淘宝：WebView加载官方H5身份码页面
- 拼多多：跳转自提点取件页
- 菜鸟：共用淘宝登录态
- 快递100 API：补充查询取件码
